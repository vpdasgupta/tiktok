Issue (Lane B): Does Illinois' biometric privacy law (BIPA) require Home Depot to get written consent before its Illinois stores use fingerprint time clocks for hourly workers?

"Probably yes. BIPA seems to cover fingerprints, and a time clock that scans a finger would be collecting them. I think Home Depot uses these clocks in Illinois, but I don't actually know. I also don't know if workers sign a consent form when they're hired. If they don't, that could be a problem."

Issue (Lane A): Does New York's pricing-label law require Home Depot to tell shoppers when a price in its app was set using their personal data?

"Maybe. The law is about prices set using a shopper's personal data. Home Depot's app probably shows some shoppers different deals, but those might be the same for everyone in an area, not based on one person's data. If the prices are personal, Home Depot would need a label, and I've never seen one."
