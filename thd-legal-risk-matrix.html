Risk Matrix: How Likely vs. How Bad

Sort each problem two ways: how likely it is to cause real legal trouble, and how bad it would be if it did. The problems that are both likely and bad are the ones your recommendation is for. Add each problem, place it in the square that fits, note your reasoning, then export the whole ranking.

How to use this tool

  • Type a problem in the box below and select Add problem. It appears in the Problems to place list.
  • On each problem, use the Move to… buttons to drop it into the square that fits. These work with a mouse, touch, or keyboard (Tab to a button, then Enter or Space).
  • On each problem, add a one-line reason, choose what sets it off, and tick This rests on a guess if your placement leans on something you're assuming about Home Depot.
  • When your placements are set, select Export to build a clean text block you can copy into your research doc.

The risk grid

This grid sorts problems two ways: how likely they are (left means unlikely, right means likely) and how bad it would be if they happened (bottom means not that bad, top means bad). The worst problems are the ones that are both likely and bad.

The grid has four squares, listed worst first: likely to happen and bad if it does; unlikely to happen but bad if it does; likely to happen but not that bad if it does; unlikely to happen and not that bad if it does. Each square's full name tells you where it sits, so you never need to see the layout.
