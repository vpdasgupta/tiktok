How the math works, in plain words
  1. Annual labor savings = price changes per year × labels per change × seconds per label swap ÷ 3,600 × labor rate.
  2. Upfront cost = number of labels × hardware per label + install + infrastructure.
  3. Annual replacement cost = number of labels × damage rate × (hardware per label + 2 minutes of labor).
  4. Net savings per year = labor savings + extra value − replacement cost − software per year.
  5. Months to breakeven = upfront cost ÷ (net savings per year ÷ 12). If net savings per year is 0 or less, it never pays back.
